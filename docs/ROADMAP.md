# Дорожная карта Donish

Отсортировано по пользе для запуска в Худжанде/Таджикистане. Монетизация (подписки, оплата) пока вне плана.

## Уже сделано

- Каталог задач по предметам и темам, автопроверка с единицами измерения и погрешностью, ручная проверка учителем.
- Условия в Markdown + LaTeX с живым предпросмотром, рисунки в условии.
- Уровни сложности 100…N (максимум задаёт админ).
- Профили учителей: сертификаты с модерацией, отзывы.
- Рейтинги учеников, школ и городов, значки, серии.
- Профиль ученика: тепловая карта активности и диаграммы по сложности.
- Олимпиады: общее окно, обязательное фото решения, автопроверка и жюри, дипломы, публикация через админа.
- Архив олимпиад и виртуальное участие.
- Интерфейс на русском, английском и таджикском; переводы условий задач.
- Каталог источников (книги, олимпиады, экзамены) и номер задачи в источнике.
- Уникальность задач: точные дубли запрещены, о похожих — предупреждение.
- Импорт задач из TXT/Markdown/Word/CSV/JSON и с фото/PDF через бесплатные модели Gemini (с выбором модели).
- Отдельная админ-панель, Docker, CI, тесты на реальной PostgreSQL.

## Этап 1. Удержание учеников (1–2 месяца)

1. **Подсказки и разборы.** 1–3 подсказки к задаче (открываются по очереди и уменьшают очки) и разбор решения, который открывается после верного ответа или после N неудачных попыток. Для олимпиад из архива — разбор от организатора.
2. **Telegram-бот.** «Задача дня», напоминания об олимпиадах, уведомления «решение проверено», «новый значок», «серия под угрозой». Привязка аккаунта по коду. Главный канал привлечения в Таджикистане.
3. **Варианты задачи с параметрами.** `{v0}` в условии генерируется для каждого ученика, ответ считается формулой. Убирает списывание ответов друг у друга.
4. **Тренировки по подборкам.** «20 задач по кинематике от 100 до 400», «Рымкевич, глава 1», «повторить нерешённые». Прогресс по подборке.
5. **Типичные ошибки.** Если ответ совпал с частой неверной формой (забыл перевести км/ч, перепутал знак), показать подсказку «проверьте единицы».

## Этап 2. Учителя и школы (2–3 месяца)

6. **Классы.** Учитель создаёт класс, ученики входят по коду-приглашению, учитель видит прогресс класса.
7. **Домашние задания.** Подборка задач с дедлайном для класса, сводная таблица «ученик × задача», экспорт в Excel.
8. **Аналитика по задаче.** Процент решивших, среднее число попыток, частые неверные ответы — помогает чинить плохие условия.
9. **Экспорт в PDF/Word.** Подборку или олимпиаду — на печать, с ответами отдельно.
10. **ИИ-помощник жюри.** Gemini читает фото решения и предлагает балл и комментарий; финальное решение за учителем. Сильно ускоряет проверку олимпиад.
11. **Переписка в попытке.** Ученик и учитель обсуждают решение внутри попытки.
12. **Командные олимпиады и турниры между школами** поверх готовых индивидуальных.

## Этап 3. Мобильное приложение для учеников

13. **PWA как первый шаг** (2–3 недели): установка на телефон, офлайн-кэш задач (дорогой мобильный интернет), съёмка решения камерой.
14. **Приложение на React Native (Expo).** Общий пакет `@kps/shared` (API-клиент, переводы, форматирование) переиспользуется. Главное: решение задач, фото решения, олимпиады, push-уведомления, профиль с картой активности. Перед этим — вынести API под версию `/api/v1` и добавить push-токены устройств.

## Этап 4. Лабораторные работы

15. **Виртуальные лабораторные по физике.** Интерактивные симуляции (маятник, наклонная плоскость, закон Ома, линзы): ученик «снимает» измерения с погрешностью, заполняет таблицу, строит график, система проверяет результат с допуском.
16. **Лабораторные по химии.** Титрование, приготовление растворов, реакции с наблюдениями — по той же схеме «измерения → таблица → вывод».
17. **Реальные лабораторные с отчётом.** Учитель задаёт лабораторную, ученик прикладывает фото установки и таблицу, учитель (или ИИ-помощник) проверяет — как в олимпиадах.

## Контент и языки

18. **Вычитка таджикского перевода** носителем языка (`frontend/packages/shared/src/i18n/tg.ts`).
19. **Узбекский интерфейс** — в Согдийской области много узбекоязычных школ.
20. **Перевод данных**: названия предметов, тем и значков, тексты ошибок сервера — сейчас только на русском.
21. **Открытый архив республиканских олимпиад** — импорт прошлых лет через импорт с фото.

## Техническое

22. **Ограничение частоты запросов** на вход, регистрацию и распознавание фото (защита от перебора и от исчерпания бесплатного лимита Gemini).
23. **Ежедневный бэкап PostgreSQL** и проверка восстановления.
24. **Sentry и метрики** (Prometheus/Grafana), логи распознавания (какая модель, сколько времени).
25. **Хранилище S3/MinIO** вместо локальной папки для фото — перед масштабированием на несколько серверов.
26. **E2E-тесты Playwright** основных сценариев в CI (вход, решение задачи, олимпиада, импорт).
27. **Деплой**: HTTPS, домен, автоматический деплой из `master`.
