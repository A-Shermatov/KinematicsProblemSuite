# Что можно добавить дальше

Отсортировано по пользе для запуска в Худжанде/Таджикистане.

## Для запуска (1–2 месяца)

1. **Telegram-бот** — «задача дня», напоминания, отправка ответа прямо в чате, уведомления ученику о проверке. Основной канал привлечения.
2. **Оплата подписки** — Alif Pay / DC / Корти Милли: бесплатные темы + платный доступ к олимпиадным. Нужна таблица `subscriptions` и флаг `is_premium` у темы.
3. **Классы (группы)** — учитель создаёт класс, выдаёт код-приглашение, видит прогресс своих учеников. Школы и репетиторы — главный B2B-клиент.
4. **Домашние задания** — подборка задач с дедлайном для класса, сводная таблица «ученик × задача».
5. **Интерфейс на таджикском и узбекском** — i18n во фронтенде (react-i18next), поле `language` у задачи.

## Для удержания

6. **Пошаговые подсказки** — 1–3 подсказки к задаче, открываются по очереди и уменьшают баллы.
7. **Разбор решения** — Markdown-разбор, который открывается после верного ответа или после N попыток.
8. **Онлайн-олимпиады** — набор задач с таймером, свой рейтинг; регулярные турниры между школами.
9. **Серии и достижения** — «7 дней подряд», «решил всю тему», значки в профиле.
10. **Варианты задачи с параметрами** — `{v0}` в условии генерируется случайно для каждого ученика, ответ считается формулой. Убирает списывание.

## Для учителей

11. **Импорт задач** из Word/Markdown/Excel пачкой и экспорт в PDF для печати.
12. **Аналитика по задаче** — процент решивших, типичные неверные ответы.
13. **Комментарии к решению** — переписка ученика и учителя внутри попытки.

## Техническое

14. **Хранилище S3/MinIO** вместо локальной папки для фото (масштабирование на несколько серверов).
15. **Ограничение запросов** на вход и регистрацию (защита от перебора паролей).
16. **Sentry + метрики Prometheus**, ежедневный бэкап PostgreSQL.
17. **E2E-тесты Playwright** основных сценариев в CI.
18. **PWA** — установка на телефон и офлайн-кэш задач (дорогой мобильный интернет).
